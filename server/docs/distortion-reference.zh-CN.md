# Brown-Conrady CPU 参考实现

**状态：** #33 的合成 CPU 参考实现已提供，不代表公共相机模型已获批准，
也不是生产或 GPU warp。首期 wire profile 仍为 pinhole。

英文版：[distortion-reference.md](distortion-reference.md)。
实现仅存在于 `server/renderer/tests/distortion_reference.rs` 的私有测试代码中；
没有新增 crate 导出、运行时控制、依赖或校准文件解释规则。

## 运行

在功能 worktree 根目录使用根开发环境：

```sh
nix develop
cargo test --locked -p chr-renderer --test distortion_reference -- --nocapture
```

测试打印 585 个合成样本的最大像素往返误差与迭代次数。不使用 GPU、窗口、
SDI 信号或私有参考数据。CPU 通过不等于 GPU、合成链路或真实校准验收通过。

## 模型与坐标顺序

仅使用三个径向系数 `(k1,k2,k3)` 与两个切向系数 `(p1,p2)`。
这是五系数多项式 Brown-Conrady 模型，不是有理、薄棱镜、倾斜传感器、
鱼眼或正交模型。Rust 私有数组分别保存径向与切向参数，不是 OpenCV
wire vector 解析器；OpenCV 五参数顺序为 `(k1,k2,p1,p2,k3)`。

理想原生像素 `(u,v)` 使用 chr 已有的含 skew 内参：

```text
y = (v - cy) / fy
x = (u - cx - skew*y) / fx
r2 = x*x + y*y
s = 1 + k1*r2 + k2*r2*r2 + k3*r2*r2*r2
xd = x*s + 2*p1*x*y + p2*(r2 + 2*x*x)
yd = y*s + p1*(r2 + 2*y*y) + 2*p2*x*y
ud = fx*xd + skew*yd + cx
vd = fy*yd + cy
```

镜头坐标 `(x,y)` 是 **K 归一化坐标，不是 SNC**。世界坐标链路为：
原始正向 `Ti * A(C)` -> SNC -> 原生像素 -> K 归一化畸变映射 -> 畸变原生像素。
回归用例包含离地世界点、负 Z 相机高度与手算像素结果，以识别直接对 SNC
应用畸变多项式的错误。

校准原生尺寸与 K 必须一起保留。输出适配是后续独立操作，不能据此静默缩放 K
或重写 Ti。像素中心不添加半像素偏移。实现使用像素位移，在不添加恒等回退分支的
情况下精确保留零畸变像素，包括边界。

## 保守的校准有效域

参考实现仅接受理想 K 归一化坐标中的圆盘 `r <= R`，且要求以下下界大于 `1e-6`：

```text
mu = 1
     - 3*max(-k1,0)*R^2
     - 5*max(-k2,0)*R^4
     - 7*max(-k3,0)*R^6
     - 6*hypot(p1,p2)*R
```

畸变 Jacobian 为对称矩阵。正径向项贡献半正定矩阵；次数为 `2n` 的负径向项，
其最小特征值损失不超过 `(2n+1)*abs(kn)*R^(2n)`。记切向向量
`t=(p2,p1)`，其 Jacobian 的特征值为
`4*dot(t,q) +/- 2*|t|*|q|`，因此下界为 `-6*|t|*R`。
在实数算术中，整个凸圆盘满足 `J >= mu*I`。沿两点连线积分即可得到
强单调性，并保证该圆盘内逆解的唯一性。

`1e-6` 裕量是保守评估限制，不是生产校准阈值或区间算术证明；
非有限算术结果会被拒绝。不满足此充分条件意味着**本参考无法认证**，
并不证明所有这类校准都无效。它不是通用的折叠/非双射校准检测或修复算法。

## 有界逆解与覆盖

逆解使用解析 2x2 Jacobian、Newton 步与使残差下降的回溯。
初值位于理想圆盘外时会投影到圆盘内；该投影只是初始猜测，不作为成功的
clamp 结果返回。每个被接受的迭代点都保留在校准圆盘内。

评估参数显式提供 1..64 个 Newton 步、每步 1..32 次回溯尝试与正的有限
归一化残差容差。合成测试使用 32 步、16 次尝试与 `1e-12`；
这些不是运行时默认值，也不保证任意内参下的统一像素精度。

成功必须满足残差收敛。预算耗尽、无法接受步骤或 Jacobian 数值不可用时返回
`NoConvergence`，不返回恒等几何。圆盘内唯一性不保证 Newton 从任意初值收敛；
失败也不证明数学逆解不存在。

求解后，源像素中心必须位于 `[0,width-1] x [0,height-1]`。
源坐标越界返回 `OutsideImage`；理想查询点超出校准圆盘返回 `OutsideDomain`。
不会将源坐标拉伸或 clamp 到边缘，也不为失败采样伪造颜色/alpha。
生产 guard band、过滤足迹、未覆盖像素策略与输出适配仍需明确设计及 GPU 测试。

## 证据与剩余门槛

测试覆盖独立手算的正向坐标、解析 Jacobian 与中心差分对照、
包含奇数尺寸/纵向尺寸的零畸变恒等、含 skew 的径向/切向/混合往返、
畸变坐标位于理想圆盘外但逆解有效的情况、有效域拒绝、不收敛、
源图像覆盖，以及 Ti/C 到原生像素的顺序。

公共实现前，#33 仍需批准模型/有效域/K/尺寸、理想与畸变 Ti 来源和 schema 演进。
GPU 逆映射采样、预乘颜色/alpha/depth 一致性、guard-band 覆盖以及防止对
已畸变实拍画面重复 warp 均未实现。本参考不会去畸变真实校准记录、
修改共享 compositor，也不证明实时性能。

## 主要参考

归一化投影公式与模型区分来自 OpenCV 公共校准文档，此处固定到

拟合数据或私有 `trd` 资产。
